# Verhaltenskodex

Wir wollen, dass sich alle hier willkommen fühlen – unabhängig von Erfahrung, Herkunft,
Geschlecht, Identität, Alter, Behinderung, Aussehen, Religion oder Weltanschauung.

**Wir erwarten:**
- freundlichen, geduldigen und respektvollen Umgang
- sachliche, konstruktive Kritik an Ideen und Code – nicht an Personen
- Rücksicht auf Einsteiger: Es gibt keine dummen Fragen

**Nicht akzeptiert werden:** Beleidigungen, Belästigung, Diskriminierung, Drohungen und das
Veröffentlichen privater Informationen anderer.

Verstöße bitte vertraulich an die Maintainer melden (über die Kontaktmöglichkeiten im
GitHub-Profil von [@enving](https://github.com/enving)). Die Maintainer können Beiträge
entfernen und Personen vom Projekt ausschließen.

Dieser Kodex orientiert sich am [Contributor Covenant 2.1](https://www.contributor-covenant.org/de/version/2/1/code_of_conduct/).
